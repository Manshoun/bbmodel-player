bbmodel-player

Play Blockbench models and their animations on any website. One script tag, one HTML element.

Source on GitHub

Drop a .bbmodel file hereIt stays in your browser, nothing gets uploaded.

Drop another .bbmodel to swap it

No model loaded

Any project saved with Blockbench works: generic, Bedrock, Java entity or GeckoLib.

Looping animations replace the base loop. One-shots like wave or attack play on top of it and then hand back to the loop. Drag to orbit, click and scroll to zoom.

Use it

<script type="module" src="https://cdn.jsdelivr.net/npm/bbmodel-player/dist/bbmodel-player.js"></script>

<bbmodel-player src="knight.bbmodel" animation="idle" controls></bbmodel-player>
import { BBModelPlayer } from 'bbmodel-player';

const player = new BBModelPlayer(document.querySelector('#stage'));
await player.load('knight.bbmodel');
player.play('walk');        // looping base animation
player.playOnce('attack');  // one-shot on top, then back to walk
srcURL of the .bbmodel file
animationlooping base animation (default idle)
controlsshow animation picker, pause, speed, reset view
auto-rotateslowly turn the model
viewfront, back, left, right or top
backgroundany CSS color, default transparent
zoomclick (default, wheel zooms after a click so the page still scrolls), always or none
staticno mouse input at all, good for galleries
